Code Playground

A real Python 3 interpreter that runs entirely in your browser (via Pyodide). No server, no signup. Try the algorithms you're learning, modify them, see the output.

How to use

Type Python in the editor below and click Run (or press Ctrl+Enter). The first run loads Python (~6 MB) and may take a few seconds. Subsequent runs are instant. Output (including print() and errors) appears in the panel underneath.

Most of the standard library is available — including collections, heapq, bisect, math, functools, itertools. No input() (you must hard-code inputs).
